Maritime radar in the littoral environment provides continuous feedback and surveillance for coastal areas, enabling users to track vessels and their immediate surroundings. Constant False Alarm Rate (CFAR) algorithms allow for dynamic filtering of background noise in radar returns. However, the parameters in One-Size-Fits-All CFAR are fragile and unreliable in real and constantly changing littoral environments.  This report aims to supply a new method of tuning CFAR parameters for more precise returns and less errors in less experienced operators. The method consists of loading a radar scene, the user marks confirmed buoy locations, the tool continuously swaps parameters of the CFAR algorithm, computes the detection performance on the ground truth buoys, and then visually presents good results for parameters. This would effectively provide a new optimization method for CFAR parameters as opposed to the current method of “vibe-coding”. (Brief Discussion of Results)

Introduction
CFAR detections is a fundamental technique in radar signal processing for maintaining a constant false alarm rate in the presence of varying clutter and noise levels in the specified environment. The performance of CFAR detectors is dependent on parameters selection, which include guard cells, reference cells, probability of false alarm, and detection variant. Guard cells provide a spatial buffer around the cell under test. Reference cells are the neighboring cells used for the estimation of noise in the environment. These variables are typically portrayed in a range of 1 to 50 cells. Probability of false alarm (PFA) provides a threshold of sensitivity for the parameters. It is typically portrayed in a range of 10^-2 to 10^-6 . There are numerous detection variants that use different calculations of these parameters to provide unique clutter removal and denoising for different environments. 
This project aims to develop a self-contained, browser-based system that enables the user to annotate their radar data with ground truth points, then performs an automated parameter optimization via grid search through a range of all 3 of the previously mentioned parameters. Once concluded the user will be able to visualize the optimization results through multiple analytical views. The project is intended to be a light, fully client-side application that will enable users to find the most optimal denoising parameter for their specific environment. 
Materials and Methods
Using a Raspberry PI 5, and a Furuno NXT DRS4D maritime radar, raw radar data was captured shoreside at Lake Murray in Columbia, South Carolina. The user selects as many ground truth targets as they would like. The system uses a “magic wand” like tool to draw a boundary around the CFAR detection, then fill the boundary with pixels, and finally displays the count of the pixels for the users. Once at least one is selected, the optimization engine is available to be run. The system then uses a grid search to systematically evaluate the combination of the parameters. The returns of the parameters are then scored based on the similarity of the return originally selected detection from the user. If a parameter completely neglects a selected ground truth from the user, it hurts the score significantly more than if it were to return a smaller area. Once all combinations of parameters have been evaluated, the results are displayed to the user in a multi-dimensional grid space, too see trends in parameters and ultimately, the most stable combination.



     Results
The website provides a fully functional CFAR detection engine with three CFAR variants, Cell-Averaging, Greatest-Of, and Smallest-Of. The user is able to see an interactive radar viewer with multi-frame support as well as a real time parameter preview. The optimizer allows users to determine the range of parameters to be adjusted as well as the step of the range to allow for even more fine tuning. A typical grid of five hundred configurations takes a few seconds to optimize and generate results. 
The area-based scoring provides significantly more nuance than a binary “if a single pixel is detected, parameters are successful”. Configurations that detect only a fragment of a target are penalized, while those capturing the full shape (80-110%) receive perfect scores. The Multi-target penalty ensures potentially optimized parameters that miss a ground truth target selected by the users are labeled as not viable.
Discussion
The strengths of this project include the low weight of the program and its ability to be run completely on the client side while providing users with intuitive workflow and real time feedback. The drawbacks are the computational constraints being hosted on web browsers, which constricts to single-threaded performance and no GPU acceleration. The input data format being CSV files is also restrictive as well as the file size being limited to 50MB due to the browser constraints. The engine also only provides the user with three very basic CFAR variants where there are numerous including specified hybrid variants. 
With these strengths and limitations identified, the product in this state has few specific-use cases. Field operators can get a quick and easy on the ground view of ground truth targets, then use this program for quick parameter tuning. In it’s current state it is an easy rapid prototype proof-of-concept before moving on to future enhancements. Those enhancements could include, multi-threaded optimization, the ability to save/load workspace sessions or optimized environments to compare, exportable optimization reports, and additional CFAR variants. 

Conclusion
The project successfully demonstrates the feasibility of deploying a fully functional CFAR parameter optimization system as a client-side web application. The system achieves core objectives of accessibility, usability, and functionality. The primary finding from testing is that the web-based approach is highly feasible for rapid deployment of radars in unique maritime environments, small to medium dataset, and interactive parameter exploration. In its current state the project is limited by computational constraints and lack of more CFAR algorithms. Overall, the system is a viable production ready too for parameter optimization in the maritime environment with clear pathways for future enhancements.
