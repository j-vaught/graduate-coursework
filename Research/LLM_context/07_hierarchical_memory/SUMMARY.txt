KEY FINDINGS
============

Memory Architecture Effectiveness:
  • Generative Agents: 2.5× believability improvement
  • MemoryBank: 78% vs 45% retrieval recall
  • HMT: 2.5-116× efficiency gains

Forgetting Patterns:
  • Human (Ebbinghaus): 50% forgotten in 1 hour
  • LoRA fine-tuning: 71% knowledge loss on old task
  • Memory replay: 11% loss (vs 71% without)
  • Sleep consolidation: 40% → 15% catastrophic forgetting reduction

Capacity Constraints:
  • Human working memory: 3-7 items ± 2
  • Transformer effective WM: 4-7 positions
  • Surprising alignment suggests fundamental limits

Metacognition Gap:
  • Human: Confidence-recall correlation r = 0.68 (well-calibrated)
  • LLM: Confidence-recall correlation r = 0.12-0.18 (poorly calibrated)
