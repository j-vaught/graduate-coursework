\section*{Questions}

\begin{enumerate}
    \item Explain the basic principle behind the Bubble Sort algorithm.
    
    \item Given the list of numbers: [4, 3, 5, 1, 2], show the sequence of steps taken by the Bubble Sort algorithm to sort this list in ascending order.

    \item What is the worst-case time complexity of the Bubble Sort algorithm? Explain why.
    
    \item Is the Bubble Sort algorithm stable? Justify your answer.
    
    \item In what scenarios would you prefer to use Bubble Sort over other more efficient sorting algorithms? Give at least one example.
\end{enumerate}

\maketitle

\section*{Answers}

\begin{enumerate}[label=\textbf{\arabic*.}]

    \item Bubble Sort works by repeatedly stepping through the list, comparing each pair of adjacent items, and swapping them if they are in the wrong order. The process is repeated until no swaps are needed, indicating the list is sorted.
    
    \item 
    Initial List: [4, 3, 5, 1, 2]
    
    Pass 1: [3, 4, 1, 2, 5] \\
    Pass 2: [3, 1, 2, 4, 5] \\
    Pass 3: [1, 2, 3, 4, 5] \\
    Pass 4: [1, 2, 3, 4, 5] (No swaps needed)
    
    Sorted List: [1, 2, 3, 4, 5]

    \item The worst-case time complexity of the Bubble Sort algorithm is \(O(n^2)\). This is because, in the worst-case, Bubble Sort would need to perform \(n(n-1)/2\) comparisons and swaps where \(n\) is the number of elements in the list.
    
    \item Yes, the Bubble Sort algorithm is stable. Stability in sorting algorithms means that when two elements have equal keys, the original sequence order is preserved. In Bubble Sort, since only adjacent elements are swapped if they are out of order, the original order of equal elements remains unchanged.
    
    \item Even though Bubble Sort is not the most efficient sorting algorithm, it might be preferred in scenarios where:
    \begin{itemize}
        \item The list is nearly sorted, and only a few elements are out of place.
        \item Memory usage is a concern, as Bubble Sort only requires a constant amount of additional memory (for swapping).
    \end{itemize}

\end{enumerate}
