\section*{Project Description}
Design a controller for a tailless jet fighter. The mathematical model of the aircraft is described by the following state equations. The controller should ensure the system tracks the following objectives:
\begin{enumerate}
    \item The desired angle of attack \( \alpha = 0.5 \) rad.
    \item The sideslip angle \( \beta = 0.2 \) rad.
    \item A steady-state error of less than 1\% for each tracked variable.
    \item A rise time of less than 0.5 seconds for each tracked variable.
    \item A maximum overshoot of 100\% for each tracked variable.
\end{enumerate}
 The state equations are based on the model described in the paper by Shtessel, Buffington, and Banda \cite{shtessel2002tailless}.
