\section{MATLAB Reproduction and Shared Functions}
The runnable scripts in \texttt{matlab/} are the same files printed with each numerical solution. From that directory, run \texttt{run\_all}. Each script displays its inputs and calculated results, checks its initial conditions, and updates the numerical data used by the Typst figures. The run also verifies the free responses against an independent matrix-exponential solution and checks final settling under changed inputs. Numerical calculations use SI units; conversion to display units occurs when producing tables and figures.

The source of the shared functions follows. Plot data are stored in \texttt{figures/src/solutions/data/}; run \texttt{make} in \texttt{figures/} to rebuild their PDFs. The MATLAB windows provide interactive data tips at the calculated event coordinates.
