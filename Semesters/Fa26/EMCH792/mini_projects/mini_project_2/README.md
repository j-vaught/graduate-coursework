# Mini Project 2

J.C. Vaught.

Run `run_project2` in MATLAB from this folder. It computes the gain with `design_controller.m`, compares the linear and nonlinear models near upright, verifies the linear closed-loop response, and builds the editable `inverted_pendulum_controlled.slx` from the inherited `inverted_pendulum_simulink.slx`. It then runs 30 s release tests at 5, 10, 20, 30, 45, and 60 degrees and random-force tests at bounds of 2.5, 5, 7.5, and 10 N. MATLAB, Simulink, and Control System Toolbox are required.

The script writes `metrics.json`, `plot_data.json`, and the two Simulink diagram images used by the report. The plot data include every sweep response, the linearization comparison, and the original held random-force sequence. The seed is 79202, the force update interval is 0.1 s, and the actuator command limit is 10 N.

Compile with `typst compile mini_project_2_report.typ mini_project_2_report.pdf`. The committed JSON files, diagrams, MATLAB functions, and `references.bib` allow the report to compile without rerunning MATLAB. All report text is single column, and all figures span the page text width. Figure 1 uses Lilaq legends at bottom left in panel (a) and top left in panel (b). Figure 2 uses one Lilaq legend at top right in panel (a), and Figure 3 uses one Lilaq legend at bottom right in panel (a). Figures 2(a) and 3(a) use symmetric logarithmic position scales that are linear within ±1 m. Figure 3(c) uses the same scale type for angle, linear within ±10 degrees. These scales retain zero and negative values while compressing large excursions. The main report contains the introductory design narrative, Results, and Discussion. Both Results paragraphs appear on the first page. The second page contains Figure 2, Discussion, and Figure 3 in that order. Its appendices contain the equations and linearization, controller design and function code, random-force protocol, detailed results, and system diagrams in that order.

Appendix A derives the upright linearization and state-space model step by step. `compare_models.m`, also called by `run_project2`, compares the uncontrolled linear and nonlinear models from initial angles of 2, 5, 10, 15, 20, 25, and 30 degrees and constant forces of 0.5, 1, 2, 4, 8, and 16 N. It writes `model_comparisons.json` with 1 s histories and absolute and percentage position and angle errors at 0.1, 0.25, and 0.5 s. The integrated linear states are checked against the exact matrix-exponential solution. Run `compare_models` alone to refresh these comparisons without rebuilding the Simulink model.

All tables have numbered captions above them and use booktabs horizontal rules. Tables 2 and 3 add vertical dividers between their three time groups. Comparison tables report percentage errors relative to the nonlinear response magnitude at each selected time. The report has two main pages, fifteen appendix pages, and one final References page. The bibliography is shared by the entire report.

Appendix B compares PID, pole placement, LQR, and MPC, then presents six Lilaq figures and three numerical tables for the linear-plant controller tests. `controller_studies.m`, also called by `run_project2`, writes `controller_studies.json`. It compares no feedback with baseline LQR, varies the angle penalty over 100, 300, and 900 and force penalty over 0.1, 0.5, and 2, and compares unlimited and 10 N limited feedback from 5 and 20 degree releases. Joint settling requires both angle within 1 degree and cart position within 0.02 m. Metrics use a 0.01 s grid over 30 s; figures use a 0.02 s grid. Run `controller_studies` alone to refresh Appendix B without rebuilding Simulink. Only the controller-design and nonlinear-acceleration functions are printed in the report.

Appendix C compares the original held disturbance with smoothing alone, rate limiting alone, and their combination. `disturbance_studies.m` generates the reversal, random profiles, and separate shaping sweeps, then runs 160 paired nonlinear Simulink trials across seeds 79202–79221 and bounds of 2.5, 5, 7.5, and 10 N. It writes `disturbance_studies.json`. The combined disturbance uses a 0.1 s low-pass time constant and 50 N/s rate limit on a 0.002 s profile grid. Shaped profiles start at zero and enter the existing source through linear interpolation; original profiles use zero-order hold. The actuator limit remains 10 N. Appendix D includes the 5 N paired response, nominal metrics, and seed summaries. Response medians in the seed table include balanced runs only. Run `disturbance_studies` alone to refresh these additions without rebuilding the saved model.
