\section*{Problem}
Given a WSS random process \(M(t)\) with the autocorrelation \(R_{MM}(\tau) = 2 \times \text{sinc}^2(5000\tau)\) as the message signal where \(max|m(t)| = 2\). The path loss is 60 dB and \(N_0 = 10^{-12}\). Determine the signal bandwidth and TX power for different analog communication schemes.

\subsection*{Signal Bandwidth}
\subsubsection*{DSB-SC AM}
For a message signal with bandwidth \(W\), the bandwidth of DSB-SC AM is \(2W\). The bandwidth is:
\[ B = 5000 \]
Hence, for DSB-SC AM:
\[ B_{\text{DSB-SC}} = 2B = 10000 \, \text{Hz} \]

\subsubsection*{Conventional AM (with \( a = 0.5 \))}
For conventional AM, the bandwidth remains:
\[ B_{AM} = B_{\text{DSB-SC}} = 10000 \, \text{Hz} \]

\subsubsection*{FM (with \( \beta = 5 \))}
Using Carson's rule for FM:
\[ B_{FM} = 2(\beta + 1)B = 60000 \, \text{Hz} \]

\subsection*{TX Power}
\subsubsection*{DSB-SC AM}
Using the given SNR equation:
\[ SNR: \frac{P_m}{P_n}=\frac{P_T \times 10^{-6}}{W \times N_0} = 10^4 \]
The TX power is:
\[ P_T = 50 \, \text{W} \]

\subsubsection*{Conventional AM (with \( a = 0.5 \))}
Using the given SNR equation:
\[ SNR = \frac{a^2 \times P_{mn}}{1 + a^2 \times P_{mn}} \times \frac{P_T \times 10^{-6}}{W \times N_0} = 10^4 \]
The TX power is:
\[ P_T = 450 \, \text{W} \]

\subsubsection*{FM (with \( \beta = 5 \))}
Using the given SNR equation:
\[ SNR: \frac{3 \times \beta^2 \times P_m}{(max(m(s)))^2} \times \frac{P_r}{W \times N_0} = 10^4 \]
The TX power is:
\[ P_T = \frac{4}{3} = 1.3333 \, \text{W} \]
