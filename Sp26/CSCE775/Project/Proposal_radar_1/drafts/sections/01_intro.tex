Marine radar is useful for tasks such as obstacle detection and local mapping, but training robust models requires large labeled datasets. Collecting and annotating real radar logs on water is expensive, so many pipelines rely heavily on synthetic radar generated in simulation. This creates a common sim-to-real gap: models that look strong in simulation can degrade when tested on real sensor data.

This proposal asks a simple question: can we automatically tune the simulator so synthetic training data better match the real world? We study a reinforcement learning (RL) controller that updates simulator parameters to maximize performance on held-out real radar validation data. The controller is conditioned on broad environment type (`lake`, `river`, `coast`), with the hypothesis that this context-aware tuning will outperform fixed settings and uniform randomization, especially on unseen routes and weather/clutter conditions.

The method builds on domain randomization and adaptive sim-to-real transfer literature \cite{tobin2017domain,peng2018sim,chebotar2018simopt,ramos2019bayessim,muratore2020bayrn,openai2019rubik,josifovski2024cdr,ho2020rap,zhao2020sim2real,kim2024soft,trinh2026digitaltwin,zust2023lars,choi2024polaris}. Prior work often uses fixed/random perturbations, one-shot adaptation, or calibration pipelines that do not explicitly model maritime environment type. Our contribution is an environment-aware RL outer loop that optimizes downstream real-task performance directly (Fig.~\ref{fig:method-overview}), with explicit comparison against related methods (Fig.~\ref{fig:rw-matrix}).
