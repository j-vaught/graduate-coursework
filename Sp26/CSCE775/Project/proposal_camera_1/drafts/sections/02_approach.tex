We formulate preprocessing control as a Markov Decision Process (MDP) in which an RL agent selects both registration and augmentation actions. As shown in Fig.~\ref{fig:method-overview}, each step follows a closed loop:
\[
\text{Input frame pair} \rightarrow \text{policy action} \rightarrow \text{processed pair} \rightarrow \text{detector feedback} \rightarrow \text{reward}.
\]

\subsection{State and Action Space}
State $s_t$ contains frame-quality statistics (e.g., blur, entropy), an initial cross-modal mismatch proxy (e.g., edge or mutual-information consistency), and optional context tags (day/night, fog/clear, rain/clear).

Action $a_t$ has two coupled components:
\begin{enumerate}
    \item \textbf{Registration family selection} $T \in \{\text{Rigid},\text{Affine},\text{Homography}\}$.
    \item \textbf{Augmentation parameters} $\lambda_{aug}$ controlling magnitude/probability of operations such as blur, thermal noise injection, intensity transforms, and modality-consistent perturbations.
\end{enumerate}

\subsection{Reward and Learning Objective}
After action execution, the downstream detector runs on processed pairs and emits task feedback. Reward is
\begin{equation}
    r_t = \alpha\,\Delta\mathcal{M}_{task} + \beta\,\Delta\mathcal{M}_{cons} - \gamma\,\mathcal{C}_{comp},
\end{equation}
where $\mathcal{M}_{task}$ is detection quality (e.g., mAP), $\mathcal{M}_{cons}$ measures cross-modal consistency, and $\mathcal{C}_{comp}$ penalizes latency.

\subsection{Policy Optimization}
We use PPO for stable policy updates in mixed discrete/continuous action spaces. To mitigate sparse reward from expensive detector retraining, we use a lightweight proxy evaluator during early policy learning and periodically refresh with full-detector validation. This setup directly targets the gap left by static augmentation and single-transform pipelines \cite{cubuk2019autoaugment,cubuk2020randaugment,zhang2020content,miao2016cnn}.
