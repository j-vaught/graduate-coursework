## Methodology


This Phase 3 analysis cross-references course requirements from the Master Analysis
 with actual course offerings from grade spread data.


**Key Definitions**:


- **Ghost Courses**: Required courses that never appear in grade spread data (0% offering)

- **Zombie Courses**: Required courses offered in less than 30% of semesters

- **Offering Rate**: Percentage of semesters where course was offered

- **Impossible Minor**: All required courses are ghost or zombie courses


## Recommendations


### IMMEDIATE PRIORITY: Data Acquisition


1. **Obtain Actual Grade Spread Data**

   - Current Excel files in usc_grade_spreads/ directory are 404 errors

   - Contact USC institutional research to obtain actual grade spread reports

   - Ensure reports include: course code, course name, semester offered, enrollment data


2. **Obtain Official Course Catalogs**

   - Get detailed requirements for each minor (specific course codes)

   - Current analysis uses generated course codes based on prefixes

   - Real analysis needs actual SUBJECT and course numbers


### ACTION ITEMS: Based on Real Data


1. **Address Impossible Minors**

   - Add required courses or restructure as electives

   - Consider consolidating with similar minors


2. **Improve Zombie Courses (< 30% offering)**

   - Establish regular rotation schedules

   - Ensure courses offered at least every other year


3. **Department-Level Support**

   - Review staffing constraints for single-department minors

   - Identify cross-listing opportunities


4. **Program-Level Reviews**

   - Audit high-risk CRITICAL minors

   - Prioritize interdisciplinary programs with multiple department dependencies
