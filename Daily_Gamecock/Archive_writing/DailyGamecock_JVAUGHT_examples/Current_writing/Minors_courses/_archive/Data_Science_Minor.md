# Data Science Minor - University of South Carolina

## Prerequisites (3-4 Hours)
Students must complete one of:
- **MATH 122**: Calculus for Business Administration and Social Sciences (3 credits)
- **MATH 141**: Calculus I (3 credits)

## Minor Core Courses (12-13 Hours)
Required selections from each group:

### Programming (Choose One)
- **CSCE 106**: Scientific Applications Programming
- **CSCE 145**: Algorithmic Design I

### Statistics (Choose One)
- **STAT 509**: Statistics for Engineers
- **STAT 515**: Statistical Methods I
- **STAT 301**: Statistical Methods for Data Analytics

### Data Analytics (Choose One)
- **CSCE/STAT 587**: Big Data Analytics
- **STAT 530**: Applied Multivariate Statistics and Data Mining

### Visualization/Computing (Choose One)
- **CSCE 567**: Visualization Tools
- **STAT 542**: Computing for Data Science
