# Foreign Language Education Minor

## Required Courses (20 credit hours)

| Course Code | Course Name | Credits |
|---|---|---|
| EDRD 500 | Content Area Literacy PK-12 | 3 |
| EDPY 401 | Learners and the Diversity of Learning | 3 |
| EDEX 491 | Introduction to Inclusion of Students with Mild Disabilities | 2 |
| EDTE 201 | Issues and Trends in Teaching and Learning | 3 |
| FORL 472 | Introduction to Technology in Language Education | 3 |
| FORL 510 | Teaching Second Languages to Young Children | 3 |
| FORL 511 | Teaching Foreign Languages in Secondary Schools | 3 |

## Elective Courses

None - All courses are required for this minor.

## Program Notes

- **Eligibility**: Available only to students majoring in French, German, Spanish, or Classics
- **Total Credit Hours**: 20
- **All courses are required**; there are no elective options within this minor
