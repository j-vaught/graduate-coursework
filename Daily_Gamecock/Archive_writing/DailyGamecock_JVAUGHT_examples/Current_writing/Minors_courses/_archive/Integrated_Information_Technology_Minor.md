# Integrated Information Technology Minor - Course Requirements

## Required Courses (6 credits)
| Course Code | Course Name | Credits |
|------------|------------|---------|
| ITEC 101 | Thriving in the Tech Age | 3 |
| ITEC 233 | Introduction to Computer Hardware and Software | 3 |

## Elective Courses (12 credits required)
Students must select 12 hours of ITEC courses from the following (excluding ITEC 143, 242, 243, 270, and 472):

| Course Code | Course Name | Credits |
|------------|------------|---------|
| ITEC 245 | Introduction to Networking | 3 |
| ITEC 264 | Computer Applications in Business I | 3 |
| ITEC 265 | Introduction to Databases | 3 |
| ITEC 293 | Cybersecurity Operations | 3 |
| ITEC 362 | Introduction to Web Systems | 3 |
| ITEC 370 | Database Systems in Information Technology | 3 |
| ITEC 445 | Advanced Networking and Security | 3 |
| ITEC 447 | Management of Information Technology | 3 |
| ITEC 493 | Information Technology Security for Managers | 3 |
| ITEC 545 | Telecommunications | 3 |
| ITEC 560 | Project Management Methods | 3 |
| ITEC 562 | Advanced Web Support Systems | 3 |
| ITEC 564 | Capstone Project for Information Technology | 3 |
| ITEC 570 | Database Management and Administration | 3 |

## Important Notes
- Total Credits Required: 18 (6 required + 12 elective)
- No course used to satisfy a Carolina Core, Major, or other Minor requirement may be used to satisfy the Integrated Information Technology Minor requirements.
- All courses use the **ITEC** prefix
