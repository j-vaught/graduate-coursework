# Aerospace Engineering Minor - University of South Carolina

## Program Overview
- **Total Credit Hours Required:** 18
- **Structure:** 3 core courses (9 hours) + 3+ elective courses (9+ hours)

## Required Core Courses (Select 3 of 5)

| Course Code | Course Title |
|-------------|--------------|
| AESP 265 | Aerodynamics I Incompressible Flow |
| AESP 420 | Flight and Orbital Mechanics |
| AESP 350 | Aerospace Systems |
| AESP 314 | Air-Breathing and Rocket Propulsion Technologies |
| AESP 466 | Flight Dynamics and Control |

## Course Statistics

- **Total Unique Courses:** 19 courses
- **Unique Prefixes:** 2 (AESP, EMCH)
- **Required Core Selection:** 3 courses from 5 AESP courses
- **Elective Selection:** 3+ courses from 19 available (5 AESP + 14 EMCH)
- **Credit Hours:** 18 minimum

## Notes

- The 5 aerospace core courses can also be selected as electives if not chosen as core requirements
- A minimum of 3 elective courses must be selected (9 credit hours)
- Mechanical engineering courses may have prerequisites in mechanical engineering fundamentals
- Source: [University of South Carolina Academic Bulletin - Aerospace Engineering Minor](https://academicbulletins.sc.edu/undergraduate/engineering-computing/mechanical-engineering/aerospace-engineering-minor/)
